# Light-glass spike: contrast tables

Generated by `python3 tools/spike-light-glass/contrast.py` - do not edit by hand.
Backdrop for every worst case: flat `#0a0a0c` (v3's dark desktop floor), no blur
needed (blur of a flat colour is the same colour). WCAG 2.x ratios; gates: text 4.5,
large text 3.0, state-carrying non-text marks 3.0; borders/dividers reported only.
`inv` = the mark is lighter than its background (polarity flipped) - unusable at that alpha.
Restructured controls use k = 0.1 (white at a fixed alpha over the panel, the dark theme's controlAlphaK model).

Gradient marks are gated on their lightest visible colour:
- readout `#f3cf7c` (right end of `#dca136 -> #f3cf7c`), eyebrow `#cf9c45`;
- spheres (status dots, thumb) `#fcecc0`, the highlight at the gradient centre;
- source glyphs: lightest painted gradient offset per glyph (optical 0.047, upnp 0.119, roon 0.000, airplay 0.000, spotify 0.000, air 0.000); worst = roon, colour `#fcecc0`.

**Fails even fully opaque (a token/design issue, not a transparency one):** Header eyebrow DEVIALET (gradient, lightest stop); IP / status line; Header caret; Settings gear; Header status dot (sphere, lightest = highlight); Readout -25.0 (gradient, lightest stop); Footer Connected; Footer dot (sphere, lightest); Slider thumb (sphere, lightest) vs panel; Slider fill vs track; Chip text Optical 1; Unmute label on active fill; Powering on... label; Source eyebrow SOURCE; Source caret; Source row glyph (gold, lightest visible); Amp list: IP line; Amp list: unconnected dot; Source list: glyph (gold, lightest visible).
